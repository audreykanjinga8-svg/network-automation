# Network Automation Project

## Description
Projet NetDevOps avec agent IA collaboratif pour l'automatisation et le monitoring réseau.

## Objectifs pédagogiques
- Centraliser toutes les configurations dans Git (GitOps)
- Déployer automatiquement via Ansible + CI/CD
- Surveiller le réseau en temps réel avec Prometheus et Grafana
- Détecter automatiquement les anomalies
- Générer et soumettre des correctifs via Pull Request avec agent IA

## Architecture et outils
- Dépôt GitOps avec playbooks et configurations
- CI/CD GitHub Actions
- Observabilité : Prometheus + Grafana
- Agent IA collaboratif (Python + PyGithub)
- Conteneurs : Docker / Podman
- Notifications Slack/Teams (optionnel)

## Résultats
- Correctifs générés automatiquement
- Branche Git pushée
- Pull Request automatique
- Dashboard Grafana affichant métriques et incidents
